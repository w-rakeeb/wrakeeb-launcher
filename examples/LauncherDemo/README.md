# Launcher Demo 1.0.0

A deliberately small standalone sample for testing real downloads, installation and independent launch. The Windows Forms application requires .NET Framework 4.8. Its optional sample note is stored under the current user's LocalAppData/Wrakeeb/Launcher Demo directory. It changes no system configuration and installs no service.

The accompanying CMD example only prints an explanation and waits for a keypress. Run it explicitly after reviewing its contents. Neither sample requires administrator privileges or the launcher to remain open.

Build the GUI with the .NET Framework C# compiler and references to System.Windows.Forms.dll and System.Drawing.dll. The versioned demo GitHub release is separate from launcher updates and is never marked latest.
