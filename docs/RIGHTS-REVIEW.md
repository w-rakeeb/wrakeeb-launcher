# Rights and distribution review — 0.4.0

Reviewed 3 November 2026. This is an engineering inventory, not a legal certification.

- Coucou: permission to redistribute the original icon, Mochi artwork and media is **not confirmed**. The v0.4.0 tree and binaries omit these assets and use a neutral catalog entry. Older public releases, archives and Git history may still contain them. Their permissions remain unresolved. They have not been deleted or rewritten because the owner requested preservation; remediation requires a separate decision. Do not assume those archives are cleared for redistribution.
- Brightness Control: original SVG and documentation screenshots come from w-rakeeb/brightness-control. Its MIT notice is preserved in references/Brightness-Control-LICENSE.txt. No replacement logo was invented.
- Other project marks/screenshots: existing project assets are unchanged; PROJECT-ASSET-SOURCES.json records sources and hashes. Project ownership and upstream brand/trademark terms still apply. Referencing Steam, Discord, GitHub or other products does not imply endorsement or confer trademark rights.
- Application code is not automatically relicensed by this review. Third-party licenses govern their respective components; no blanket MIT license is granted to this launcher or its artwork.
- THIRD-PARTY-NOTICES.txt and DEPENDENCY-LICENSES.json inventory resolved Rust Windows and installed npm packages, including build dependencies. Repeated identical license texts are referenced once. Supplemental upstream notices retain provenance. selectors 0.38.0 is unmodified; its MPL source is available at https://crates.io/crates/selectors/0.38.0 . stackback 0.0.2 is test-only, excluded from production, and declares MIT but omits a root license text; that inventory exception is retained.
- No catalog application's executable is bundled into the launcher. Downloading an application remains subject to its own license and requirements.

Before wider redistribution, resolve the historical Coucou artwork issue and obtain professional advice if a formal rights opinion is required.
