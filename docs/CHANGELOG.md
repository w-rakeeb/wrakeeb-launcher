# Release history

## 0.3.0 — 2 November 2026

Added actual GitHub project downloads, SHA-256/size verification, safe portable ZIP extraction, independent application installation, installation receipts and explicit launch. Added standalone GUI and CMD demos. Local .exe/.cmd/.bat/.ps1 linking is supported. Downloads and installation roots are configured separately; existing versions/data remain preserved.

Added a current-user Windows NSIS installer with WebView2 bootstrapper handling, Windows 10+ gate, desktop shortcut action, live repository/release information, asset names/sizes/checksums, release notes, ten-minute metadata caching and direct GitHub source/history links.

Expanded the catalog to ten projects with precise descriptions and added original project screenshots. Added Slate/Corporate light themes and five accent options. Replaced decorative onboarding with a real installation guide, refined detail/download layouts and copy, improved keyboard tab controls, and removed page/card entrance animation.

Restoration: retained 0.2.0 and archived recovered 0.1.0/0.1.1 executable/source snapshots with explicit completeness notes. New release assets are never used to overwrite older versions.

## 0.2.0 — 2 November 2026

Dual Discord default colors; original charcoal retained. Integrated title bar and supplied Wrakeeb logo. Consistent project-logo covers with original screenshot galleries. Settings tabs, reduced motion and restrained interaction animation.

Configurable local download location and launcher updates: stable GitHub checks, persistent feedback, release notes, cancellable real downloads, SHA-256/size verification, executable backups, automatic replacement/restart and startup-failure rollback. Optional background checks do not gate local use.

Local linking, favorites, search, views, activity and existing data remain compatible. Individual app installation and app-update packages are not included.

Original project imagery, captions, gallery and full-size viewing.

## 0.1.0

Working local library, executable linking/launching, discovery, favorites, preferences and activity.
